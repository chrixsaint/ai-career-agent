# Project Learning Path

> **Purpose:** This document defines the official learning roadmap for building the AI Career Agent. It provides a structured sequence of technologies, concepts, and implementation milestones so that every topic learned contributes directly to the project.

---

# Learning Philosophy

This project is not about learning technologies in isolation.

Every concept should follow this cycle:

Learn

↓

Understand

↓

Build a small example

↓

Apply it to the AI Career Agent

↓

Document what was learned

↓

Improve the project

Learning is only complete when the concept has been successfully applied.

---

# Primary Goal

Build a production-quality AI Career Agent while developing strong backend engineering, AI engineering, and software architecture skills.

The project should emphasize:

- Clean code
- Maintainable architecture
- Practical AI integration
- Automation
- Testing
- Documentation
- Continuous learning

# Continuous Learning

Throughout every phase:

- Read official documentation first.
- Watch high-quality technical videos.
- Organize resources in the knowledge base.
- Upload curated resources to NotebookLM.
- Update cheat sheets.
- Record implementation lessons.

Learning should happen continuously rather than only before coding.

---

# AI Collaboration

When working with AI assistants:

- Ask for explanations before implementations when learning new concepts.
- Request production-quality code.
- Ask for trade-offs between different approaches.
- Prefer reusable solutions over shortcuts.
- Review generated code before accepting it.
- Update documentation after major implementation decisions.

---

# Success Criteria

This learning path is successful when you can:

- Explain the architecture of the AI Career Agent.
- Build new features confidently.
- Debug problems independently.
- Integrate new AI providers with minimal changes.
- Maintain clean documentation.
- Use AI as a collaborative engineering partner rather than a code generator.
