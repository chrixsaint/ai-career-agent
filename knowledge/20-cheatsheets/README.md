# Engineering Playbook

Welcome to the Engineering Playbook.

This playbook contains reusable engineering knowledge collected while building the AI Career Agent.

## Purpose

Instead of memorizing commands, workflows, and best practices, document them once and let the AI Career Agent retrieve them when needed.

## Structure

- `git.md` — Git commands
- `workflows.md` — Common engineering workflows
- `linux-terminal.md` — Linux terminal commands
- `vscode.md` — VS Code commands and shortcuts
- `github.md` — GitHub workflows
- `python.md` — Python commands
- `best-practices.md` — Engineering conventions
- `troubleshooting.md` — Problems and solutions
- `glossary.md` — Engineering terminology

## Rules

1. Only document commands that have been used.
2. Every command should include aliases.
3. Every command should reference related workflows.
4. Every workflow should be tested.
5. Update the playbook as the project evolves.

## Philosophy

Learn once.
Document once.
Reuse forever.
