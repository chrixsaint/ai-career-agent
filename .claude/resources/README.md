# AI Engineering Resources

> **Purpose:** This directory contains reusable resources that support the AI-assisted development workflow for the AI Career Agent.

Unlike the project documentation in `docs/`, these resources are **not** the source of truth for the project.

They exist to improve developer productivity by providing reusable operational resources for AI-assisted engineering.

---

# Responsibilities

Resources in this directory support day-to-day development activities, including:

- Frequently used commands
- Reusable prompts
- Curated official documentation references
- AI engineering workflows

---

# What Belongs Here

Examples include:

- Reusable NotebookLM prompts
- Reusable ChatGPT prompts
- Reusable Claude Code prompts
- Frequently used terminal commands
- VS Code command references
- Curated links to official documentation
- AI engineering reference material

---

# What Does NOT Belong Here

This directory should not contain:

- Project requirements
- Project architecture
- Roadmaps
- Project status
- Source code
- Tests
- Duplicate copies of official documentation
- Long tutorials
- Temporary notes

Those belong elsewhere in the repository or should be retrieved from official sources when needed.

---

# Design Principles

Resources should be:

- Reusable
- Concise
- Well organized
- Easy to maintain
- Focused on long-term usefulness

When possible, prefer links to official documentation over copied content.

---

# Relationship to the Repository

- `docs/` defines the project.
- `app/` contains the implementation.
- `tests/` verifies the implementation.
- `.claude/` supports AI-assisted engineering.

This directory exists to support the developer rather than define the project itself.
