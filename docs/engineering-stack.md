# Engineering Stack

## Philosophy

The AI Career Agent is built using technologies that are:

- Open source whenever practical
- Cost-effective to develop and operate
- Modular and easy to maintain
- Well documented
- Widely adopted by the developer community
- Suitable for long-term scalability

## Design Principles

The engineering stack follows these principles:

1. Prefer open-source technologies where practical.
2. Minimize operational costs.
3. Keep components modular and independently replaceable.
4. Adopt widely supported technologies with strong documentation.
5. Prioritize maintainability over unnecessary complexity.
6. Design for future scalability without overengineering the initial implementation.

---

## Future Evaluation

The engineering stack will evolve as the project grows. New technologies will only be adopted if they provide clear advantages in reliability, maintainability, developer productivity, or operational cost.
