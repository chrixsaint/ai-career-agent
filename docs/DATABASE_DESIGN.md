# Database Design

## Purpose

This document describes the high-level data model for the AI Career Agent.

It defines the core entities, their responsibilities, and the relationships between them. It is intended to guide database implementation and API development.

---

# Design Principles

The database should:

- Store normalized data.
- Avoid unnecessary duplication.
- Be easy to extend.
- Support multiple job sources.
- Support multiple career profiles.
- Preserve historical data where useful.

---

# Core Entities

## Job

Represents a single job opportunity collected from a job source.

### Key Information

- Job ID
- Title
- Description
- Employment Type
- Experience Level
- Location
- Remote Status
- Salary (if available)
- Date Posted
- Application Deadline (if available)
- Job URL
- Source
- Status

---

## Company

Represents the organization offering a job.

### Key Information

- Company ID
- Company Name
- Industry
- Website
- Headquarters
- Careers Page

---

## Job Source

Represents where a job was collected.

Examples include:

- Public APIs
- Company career pages
- Approved web scrapers

### Key Information

- Source ID
- Source Name
- Source Type
- Base URL
- Collection Method

---

## Career Profile

Represents a career category supported by the system.

Examples:

- Software Engineering
- Biomedical Engineering
- Biochemistry
- Hybrid Careers

### Key Information

- Profile ID
- Profile Name
- Description

---

## User Profile

Represents the user's career preferences.

### Key Information

- Preferred Locations
- Preferred Job Types
- Career Interests
- Skills
- Experience
- Education

---

## CV

Represents a version of the user's CV.

### Key Information

- CV ID
- Version
- Creation Date
- Target Career Profile
- File Location

---

## Cover Letter

Represents an AI-generated cover letter.

### Key Information

- Cover Letter ID
- Job
- Company
- Creation Date
- Version

---

## Job Recommendation

Represents a recommendation generated by the ranking system.

### Key Information

- Recommendation ID
- Job
- Recommendation Score
- Ranking Position
- AI Explanation
- Date Generated

---

# Relationships

- A Company can have many Jobs.
- A Job belongs to one Company.
- A Job originates from one Job Source.
- A Job can belong to multiple Career Profiles.
- A User Profile can have multiple CV versions.
- A Job can have multiple tailored CVs.
- A Job can have multiple Cover Letters.
- A Job Recommendation references one Job.
