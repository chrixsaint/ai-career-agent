# Project Vision

> **Purpose:** This document defines the long-term vision of the AI Career Agent. It explains why the project exists, the problems it aims to solve, and the principles that guide its evolution.

Implementation details belong in `ARCHITECTURE.md`.

Project requirements belong in `REQUIREMENTS.md`.

Development planning belongs in `ROADMAP.md`.

---

# Mission

Build a personal AI career assistant that continuously discovers relevant job opportunities and helps prepare high-quality, user-controlled applications.

The system should reduce the time spent searching for jobs while improving the quality and consistency of every application.

---

# Problem Statement

Searching for relevant job opportunities manually is repetitive, time-consuming, and inefficient.

New opportunities often receive hundreds of applications shortly after publication.

Preparing tailored CVs and cover letters for every opportunity requires significant effort and limits the number of high-quality applications that can be submitted.

The project aims to automate repetitive tasks while keeping the user in full control of every application.

---

# Long-Term Vision

The AI Career Agent should become a long-term career companion.

It should continuously:

- Discover relevant opportunities.
- Learn the user's career interests.
- Improve recommendation quality.
- Assist with application preparation.
- Support long-term career growth.

The system should adapt as the user's skills, experience, and career goals evolve.

# Guiding Principles

The project is guided by the following principles.

- User-first.
- AI-assisted, not AI-controlled.
- Open-source where practical.
- Modular by design.
- Maintainable over complex.
- Incremental improvement.
- Human approval before application submission.

---

# Success Criteria

The project succeeds if it helps the user:

- Discover relevant opportunities earlier.
- Spend less time searching for jobs.
- Prepare higher-quality applications.
- Increase interview opportunities.
- Build a sustainable long-term career workflow.
